# Razonamiento Visual y UX

## Segunda iteración

Esta iteración busca alejarse de la sensación de prototipo funcional y acercarse a una propuesta visual más defendible frente a cliente.

## Dirección visual

- luminosa
- biomédica
- institucional
- contemporánea
- sobria

Se evita el lenguaje típico de admin dashboard:

- demasiadas cards iguales
- color plano sin narrativa
- tipografía neutra sin jerarquía
- tablas sin presencia

## Referencias reinterpretadas

La inspiración funcional viene de All of Us Data Browser, pero adaptada a MePRAM:

- browser de datos públicos agregados
- navegación por dominios
- búsqueda transversal
- breakdown descriptivo
- concepto como unidad de detalle

No se copia el look and feel. Se reinterpreta con una paleta más clínica y un framing más europeo e institucional.

## Jerarquía UX

### Home

Debe responder rápido a tres preguntas:

1. Qué es MePRAM.
2. Qué tamaño y profundidad tiene la cohorte.
3. Por dónde empiezo a explorar.

### Catálogo

Debe sentirse como una herramienta de trabajo:

- búsqueda visible
- filtros inmediatos
- tabla densa pero legible
- acceso rápido al detalle

### Detalle de concepto

Debe inspirar confianza:

- métricas arriba
- gráficos simples y comprensibles
- metadatos terminológicos claros
- recordatorio constante de que todo son agregados

## Criterios de implementación

- responsive sin perder densidad informativa
- componentes reutilizables
- buena legibilidad a primera vista
- narrativa visual suficiente para una demo con cliente
